# AI_LAB_13-KNN-

# Lab 13 – KNN Classification (Machine Learning)

This project implements the **K-Nearest Neighbors (KNN)** algorithm using Python and Jupyter Notebook.  
The objective is to analyze how feature scaling, hyperparameter tuning, evaluation metrics, and feature selection impact model performance, particularly in a medical (cancer detection) scenario.

## Tasks Covered
- Importance of feature scaling in distance-based algorithms
- Hyperparameter tuning (number of neighbors, weights, distance metric)
- Clinical priority analysis focusing on False Negatives and Recall
- Performance comparison using reduced feature sets

## Dataset
- Breast Cancer dataset from `scikit-learn`

## Technologies Used
- Python
- Jupyter Notebook
- NumPy
- Pandas
- Scikit-learn

## How to Run
1. Open the notebook in Jupyter
2. Run cells sequentially using **Shift + Enter**
3. Observe outputs and analysis in each section

## Conclusion
The lab highlights that proper preprocessing and metric selection are critical for KNN performance. In healthcare-related applications, recall should be prioritized to reduce the risk of false negatives.
